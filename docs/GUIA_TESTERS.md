# Typing Survivor — versión de prueba para Windows

1. Descomprime **todo** el ZIP en una carpeta.
2. Abre `TypingSurvivor\TypingSurvivor.exe`. Mantén el ejecutable y la carpeta `_internal` juntos.
3. Juega con el teclado: escribe las palabras de los enemigos; `1`–`4` activan los potenciadores, `Esc` pausa y `F11` cambia a pantalla completa. Los menús también aceptan ratón.

Prueba las tres dificultades y, si llegas a ellas, las rondas de jefe 5 y 10. Al terminar una partida, entra en la Tienda, compra una mejora y comprueba que siga activa tras cerrar y volver a abrir el juego. Los puntos se añaden al saldo al terminar cada partida.

Si encuentras un fallo, comunica a Manu la dificultad, la oleada, los pasos para reproducirlo y qué ocurrió. Una captura de pantalla también ayuda.

El progreso se guarda en `%LOCALAPPDATA%\TypingSurvivor\save_data.json`. Este archivo no va dentro del ZIP ni se borra al actualizar el juego.
